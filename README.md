# java-calculator-precourse

-------

## 🔥구현할 기능 목록

### ⌨️ 입력 기능
 - [x] 문자열 입력 안내 메시지를 출력한다.
 - [x] 구분자와 양수로 구성된 문자열을 입력 받는다.

### 구분 기능
 - [x] 쉼표(,) 또는 콜론(:)을 구분자로 가지는 문자열을 전달하는 경우, 해당 구분자를 기준으로 구분한 숫자를 반환한다.
 - [x] "//"와 "\n"사이에 위치하면 커스텀 구분자이며, 해당 구분자를 기준으로 구분한 숫자를 반환한다.
 - [x] 반환받은 숫자를 저장한다.
 - [x] 구분 가능한 문자열 이외에는 예외 처리를 한다.

### 🧮 계산 기능
 - [x] 저장한 숫자를 합한다.

### ✖️ 예외 처리 기능
 - [x] 구분자가 포함되지 않은 경우 예외 처리한다.
 - [x] 공백이 포함된 경우 예외 처리한다.
 - [x] 숫자가 하나라도 0인 경우 예외 처리한다.
 - [x] 숫자가 없는 문자열은 예외 처리한다.
 - [x] 커스텀 구분자는 두 글자 이상이면 예외 처리한다.
 - [x] 커스텀 구분자는 숫자이면 예외 처리한다. 

### 🖥️ 출력 기능
 - [x] 입력받은 문자열을 토대로 계산한 결과를 출력한다.
